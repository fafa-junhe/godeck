# GoDeck 原生桌面客户端 (Arch Linux)

GoDeck 是一款基于 Go / Gio 框架构建的高性能、端到端加密远程桌面客户端。
本安装包针对 **Arch Linux + KDE Plasma Wayland + Intel Haswell-ULT / Mesa (OpenGL/EGL + PipeWire + FFmpeg VA-API)** 环境进行原生适配构建。

---

## 一、软件定位与核心特性

1. **双向合一**：同一个原生客户端既可作为**主控端**（发起远程桌面会话、文件传输），又可作为**被控端**（接受受控来访、屏幕画面实时推流）。
2. **纯原生渲染**：基于 Gio 图形框架使用 `-tags novulkan` 构建，完全运行于 Mesa 原生 OpenGL/EGL 之上，不依赖 Vulkan，不启用 Zink 中间层。
3. **硬件加速与回退**：
   - 优先通过 Intel i965 驱动（`libva-intel-driver`）实现 VA-API 硬件级 H.264 快速编解码；
   - 自动内置软编码（`x264enc`）与软解码（`avdec_h264`）回退链路。
4. **KDE Wayland 门户集成与原生 IME 支持**：
   - 完整实现 Wayland 原生 `zwp_text_input_v3` 协议，全面支持 Fcitx5 中文输入法，输入框光标跟随与候选词窗口精准定位；
   - 通过 `xdg-desktop-portal-kde` 与 `pipewire` 实现 Wayland 下的高帧率屏幕捕获与精确键鼠输入注入；
   - 远程连接中支持随时按 **F2** 快捷键切换/查看实时统计数据浮层（网络码率、编解码器与速率、分辨率、帧率、丢包延迟等）。

---

## 二、启动与使用方式

- **应用菜单启动**：在 KDE 启动菜单（Kickoff / KRunner）中搜索 **GoDeck**，点击图标启动。
- **命令行启动**：
  ```sh
  godeck
  ```

---

## 三、连接公网中心 (Hub) 接入步骤

1. **公网中心地址**：`https://godeck.junher.top:8443`
2. **首次初始化主人账号**：
   - 若中心服务尚未初始化，首次可在【设备】页面输入该地址、自拟主人用户名与密码，并填入管理员通过 SSH 在服务器上读取的一次性 Setup Code，点击“初始化主人账号并登录”。
3. **两端登录与绑定**：
   - 控制端电脑与被控端电脑均打开 GoDeck，进入【设备】页面输入中心地址与主人账号登录。
   - 在需要被远程控制的机器上点击 **“绑定本机到中心”**，设备即可在中心完成持久注册。
4. **发起远程控制与本地授权**：
   - 控制端在设备列表中点击在线设备发起连接。
   - **被控端桌面将弹出授权审批卡片**（可选择“允许查看画面”或“允许桌面控制”及文件传输），确认后即建立端到端加密连接。

---

## 四、安全与系统权限说明

- 本安装包不包含开机自启后台服务，不占用 root 权限，不预装任何账号凭据或密钥。
- 在 KDE Plasma Wayland 环境下，受控时系统级 Desktop Portal 将主动提示用户确认屏幕共享与远程输入权限。
- 可选调试工具：安装 `libva-utils` 可通过 `vainfo` 命令检验 Intel Haswell 核显的 VA-API 硬解就绪状态。
